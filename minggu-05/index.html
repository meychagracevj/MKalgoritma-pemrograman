♡ Bagaimana Bubble Sort Bekerja?

Bubble Sort bekerja dengan membandingkan dua nilai yang berdekatan. Jika urutannya belum sesuai, kedua nilai ditukar. Proses ini diulang sampai seluruh data tersusun sesuai pilihan.

Ascending: nilai terendah menuju tertinggi.
Descending: nilai tertinggi menuju terendah.

Pilih urutan dan klik tombol untuk memulai.
